# ZeroControlStudios

**ZeroControlStudios** is an independent software and game development studio focused on creating original software, games, mods, server infrastructure, and other digital projects.

Founded in 2025, the studio develops and maintains its own projects across software development, game development, modding, and server infrastructure.
